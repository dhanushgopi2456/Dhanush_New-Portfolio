# 🚀 Dhanush Gopi | Developer Portfolio

A responsive, high-performance personal portfolio showcasing my software engineering projects, technical skills, and experience. Built with modern web technologies and integrated with AI capabilities powered by Google Gemini.

---

## ✨ Features

- **Interactive AI Assistant:** Powered by the Google Gemini API to answer questions about my background, skills, and projects.
- **Dynamic Projects Showcase:** Clean grid view with direct links to live demos and GitHub repositories.
- **Skills & Experience Section:** Structured layout detailing frontend, backend, tools, and tech stack proficiency.
- **Contact Form:** Direct communication channel integrated for recruiters and clients.
- **Fully Responsive & Modern UI:** Designed with a mobile-first approach and smooth interactions.

---

## 🛠 Tech Stack

* **Frontend:** React, TypeScript, Vite
* **Styling:** Tailwind CSS, Lucide Icons
* **AI Integration:** Google Gemini API
* **Deployment:** Vercel

---
