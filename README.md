# 🚦 Run Locally

## Prerequisites

```text
Node.js 18+
npm
Git
VS Code
```

### Clone

```bash
git clone https://github.com/dhanushgopi2456/Dhanush_New-Portfolio.git
cd Dhanush_New-Portfolio
```

### Install

```bash
npm install
```

### Start

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```
