# 🚀 Dhanush Gopi | Developer Portfolio

A responsive, high-performance personal portfolio showcasing my software engineering projects, technical skills, and experience. Built with modern web technologies and integrated with AI capabilities powered by Google Gemini.

---

## ✨ Features

- **Interactive AI Assistant:** Powered by the Google Gemini API to answer questions about my background, skills, and projects.
- **Dynamic Projects Showcase:** Clean grid view with direct links to live demos and GitHub repositories.
- **Skills & Experience Section:** Structured layout detailing frontend, backend, tools, and tech stack proficiency.
- **Contact Form:** Direct communication channel integrated for recruiters and clients.
- **Fully Responsive & Modern UI:** Designed with a mobile-first approach and smooth interactions.

---

## 🛠 Tech Stack

* **Frontend:** React, TypeScript, Vite
* **Styling:** Tailwind CSS, Lucide Icons
* **AI Integration:** Google Gemini API
* **Deployment:** Vercel

## 🚦 Getting Started Locally

### Prerequisites

Ensure you have **Node.js** (v18 or higher) installed on your system.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/dhanushgopi2456/Dhanush_New-Portfolio.git
   cd Dhanush_New-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Create a `.env` file in the root directory and add your Gemini API key:
   ```env
   VITE_GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:5173`.

---

## ⚙️ Deployment

This project is optimized for deployment on **Vercel**:

1. Import your GitHub repository into Vercel.
2. Set the **Root Directory** to `Dhanush_New-Portfolio-main` (or your project subfolder).
3. Add `VITE_GEMINI_API_KEY` to the **Environment Variables** section in Vercel.
4. Click **Deploy**.
