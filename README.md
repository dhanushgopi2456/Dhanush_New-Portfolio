# 🚦 Run Locally

### 1️⃣ Clone

```bash
git clone https://github.com/dhanushgopi2456/Dhanush_New-Portfolio.git
cd Dhanush_New-Portfolio
```

### 2️⃣ Install

```bash
npm install
```

### 3️⃣ Start

```bash
npm run dev
```

### 4️⃣ Open

```text
http://localhost:5173
```
